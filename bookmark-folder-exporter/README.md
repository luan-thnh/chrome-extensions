# Bookmark Folder Exporter v1.2.0

Chrome Extension (Manifest V3) để quản lý và xuất bookmark theo folder.

## Tính năng

- Chọn **nhiều folder** bookmark cùng lúc.
- Tùy chọn lấy toàn bộ **folder con**.
- Tìm folder theo tên / đường dẫn.
- Lọc kết quả theo **từ khóa** và **domain**.
- Tùy chọn chỉ lấy link `http://` / `https://`.
- Phát hiện và **loại link trùng** theo URL.
- Sắp xếp theo bookmark gốc, title, folder hoặc ngày thêm.
- Preview dữ liệu và thống kê link / folder / domain / link trùng.
- Sao chép nhanh toàn bộ URL sau khi lọc.
- Xuất **Excel .xlsx thật** hoặc CSV.
- Nhớ folder đã chọn, bộ lọc và Dark/Light theme.
- Hoạt động local, không gửi bookmark lên server.

## Cài đặt

1. Giải nén ZIP.
2. Mở `chrome://extensions`.
3. Bật **Developer mode**.
4. Chọn **Load unpacked**.
5. Chọn folder `bookmark-folder-exporter`.
